# 🎂 RoboBirthday

اپ تولد با Flutter (اندروید). APK به‌صورت خودکار با GitHub Actions ساخته می‌شود.

## دانلود APK
1. تب **Actions** ← آخرین اجرای «Build APK» ← بخش **Artifacts** ← `RoboBirthday-apk`
2. یا با ساخت تگ (مثلاً `v1.0.0`) فایل APK در بخش **Releases** قرار می‌گیرد.

## ساخت دستی
بعد از هر push روی `main` خودکار اجرا می‌شود، یا از تب Actions دکمه‌ی **Run workflow**.
